# Statistic: Kotlin/Native <-> C++23 interop

Kotlin/Native (linuxX64) calls `libstatslib.so` (C++23 behind a pure C API) through cinterop.

## Requirements (Debian 13)

    sudo apt install build-essential cmake openjdk-21-jdk

GCC 14 (C++23: `<expected>`, `<span>`, `ranges::fold_left`), CMake >= 3.25, JDK 17+ for Gradle.
Kotlin 2.4.0 and Gradle 9.5.0 are pinned in `build.gradle.kts` / `gradle-wrapper.properties`.

## Commands

    ./gradlew runReleaseExecutableLinuxX64                      # builds the .so, then runs on data/sample.csv
    ./gradlew runReleaseExecutableLinuxX64 -Pstatistic.csv=path # another input file
    ./gradlew linuxX64Test                                      # Kotlin interop tests
    ./gradlew nativeTest                                        # C++ tests (ctest)
    ./gradlew check                                             # everything

## Layout

    native/                      C++ project (core, CSV reader, C API, tests)
    lib/libstatslib.so           generated by CMake via the cmakeBuild task
    src/nativeInterop/cinterop/  statslib.def  (header + -lstatslib)
    src/main/kotlin/             Stats.kt (interop wrapper), NumberParser.kt, FileReading.kt, main.kt
    src/test/kotlin/             parser tests + interop round-trip tests

## Troubleshooting

- Link error about `libstdc++` / `GLIBCXX`: rebuild with `-Pstatistic.staticCxx=ON`
  (then `./gradlew clean` first, so the .so is regenerated).
- `libstatslib.so: cannot open shared object file` when running the .kexe by hand: the rpath
  points to `<project>/lib`; if you moved the binary, set `LD_LIBRARY_PATH` to that folder.
